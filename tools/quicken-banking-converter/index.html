1 · Activity exports

    Exports are combined in date order; rows repeated across overlapping exports are kept once. Runs entirely in your browser — files are never uploaded.

    2 · Accounts

    Name each account as it appears in Quicken. Investment accounts start unticked — use the Quicken Investment Converter for those.

    3 · Transaction date

    Executed date is the "executed at" date in the description — the same date the investment converter uses, so transfers between accounts line up.

    Importing

    In Quicken for Windows use File › File Import, then the CSV or QIF File option. For QIF, pick the account — ignore the dialog's note that QIF isn't available for this account type. Neither format skips duplicates, so import each month only once.

    Account names, payees and categories are remembered on this device only.

    Choose one or more Wealthsimple activities-export CSVs on the left to preview the Quicken import.
